## 📖 О проекте

Стандартные загрузчики видео и анимации в ComfyUI распаковывают весь файл целиком в несжатые тензоры `float32` в оперативной памяти (RAM). Например, видео из 5000 кадров в разрешении `1280×720` на старте съедает **~58 ГБ RAM** и ещё **~58 ГБ** внутри `VAEDecode`, что приводит к мгновенному переполнению памяти (OOM) даже на рабочих станциях с 64 ГБ ОЗУ.

**ComfyUI-Blackbox-Media** устраняет это архитектурное ограничение движка ComfyUI за счёт комбинации **ленивого декодирования кадров по запросу (`Lazy Frame Decoding`)**, **транзакционного авто-чанкинга (`Two-Phase Commit Auto-Chunking`)**, **бесшовного оптического дефликера `RAFT` на стыках чанков** и **потокового кодирования через пайпы `ffmpeg`**.

Поместите **любой** существующий граф обработки одиночной картинки (Flux, SDXL, ControlNet, апскейлеры, Inpainting, Face Detailer) внутрь условного **«Чёрного ящика» (Blackbox)** и обрабатывайте видеоролики, GIF, WebP или папки с раскадровкой любой длины и разрешения с минимальным расходом памяти.

## ✨ Ключевые инженерные особенности

* **Ленивое чтение с нулевым расходом RAM на старте (`LazyVideoFrameList` & `LazySequenceFrameList`):** Открывает многогигабайтные видеофайлы (`.mp4`, `.mkv`, `.webm`, `.mov`, `.avi`) или папки с тысячами картинок за `0.01 сек`. Кадры декодируются из потока строго по одному в момент обращения.
* **Транзакционный авто-чанкинг (Two-Phase Commit):** Разбивает длинные видео на безопасные пачки (например, по `chunk_size = 50` кадров). Каждый чанк проходит сквозь `VAEDecode`, потребляя всего ~500 МБ RAM, атомарно фиксируется на диске в `Saver`, вызывает очистку кэша ComfyUI (`/free`) и автоматически запускает следующий чанк с расчётом оставшегося времени (**ETA**).
* **Защита от сбоев и возможность докачки (Resume):** Ни `Loader`, ни `Deflicker` не перезаписывают боевое состояние сессии заранее — коммит происходит только после записи чанка в `Saver`. Если рендер прервался ошибкой или кнопкой `Cancel`, при следующем запуске вы можете либо **начать чисто с 0-го кадра (`Restart from 0`)**, либо **продолжить с последнего сохранённого чанка (`Resume`)**.
* **Бесшовный дефликер на базе оптического потока RAFT:** Убирает нейросетевое мерцание и скачки яркости между кадрами с помощью двунаправленного оптического потока **RAFT** (с маской окклюзий и шлейфов в FP16) и скользящей стабилизации гистограммы в пространстве **LAB**. Эталон цвета и хвосты кадров передаются между чанками, делая стыки чанков абсолютно невидимыми.
* **Скользящий кэш в VRAM (`pin_memory` + `LRU`):** В видеопамяти одновременно хранится только `2 * window_radius + 1` кадров. Каждый кадр передаётся по шине PCIe (`CPU -> GPU`) ровно один раз.
* **Универсальный муксер FFmpeg и озвучка GIF:** Кодирует поток напрямую в пайп `ffmpeg` (`MP4 H.264 + AAC` или `WebM VP9 + Opus`), а также в `24-bit TrueColor WebP` и `256-цветный GIF с общей мастер-палитрой`. Автоматически подрезает, разворачивает (`areverse`) и синхронизирует темп звука (`atempo`) при изменении скорости видео, а также позволяет **озвучить немой GIF/WebP** от любой сторонней аудио-ноды ComfyUI.

## 🧩 Описание нод

### 1. `Blackbox Media Loader`
Загружает видеофайлы, анимированные GIF, WebP или папки с последовательностью кадров и выдаёт покадровый список (`OUTPUT_IS_LIST = True`) для подачи в «Чёрный ящик».

| Параметр / Элемент | Тип | Описание |
| :--- | :--- | :--- |
| **Интерактивный плеер** | `DOM Widget` | Масштабируемый плеер с перемоткой, покадровым шагом и отображением задержек. |
| **📁 Select Video / GIF / WebP File...** | `Button` | Загрузка и выбор медиафайла через системное окно ОС. |
| **📂 Select Image Sequence Folder...** | `Button` | Выбор папки с кадрами (естественная сортировка `frame_1.png` ... `frame_10.png`). |
| **🔄 Reset Chunk Progress** | `Button` | Ручной сброс прогресса чанков на 0-й кадр. |
| `media_source` | `COMBO` | Выбор файла из папки `ComfyUI/input/`. |
| `start_frame` | `INT` | Индекс начального кадра (с 0). |
| `max_frames` | `INT` | Лимит кадров для обработки (`0` = весь файл до конца). |
| `frame_skip` | `INT` | Шаг прореживания кадров (`1` = каждый кадр, `2` = каждый второй и т.д.). |
| `chunk_size` | `INT` | Размер одного чанка за проход графа (`50` по умолчанию; `0` = без чанкинга). |
| `if_interrupted` | `COMBO` | Поведение после сбоя: `Restart from 0` (сначала) или `Resume` (продолжить). |
| `sequence_fps` | `FLOAT` | Базовая частота кадров (FPS) при загрузке папки с картинками. |
| `custom_path` *(опц.)* | `STRING` | Прямой путь к файлу или папке с секвенцией кадров. |

**Выходы:** `image_list` (`IMAGE`), `stream_meta` (`BLACKBOX_STREAM_META`), `audio` (`AUDIO`).

---

### 2. `Blackbox Media Inspector`
Узел глубокой телеметрии медиапотока и расчёта геометрии.

* **Информационное табло на ноде:** Выводит формат контейнера, видео/аудио кодеки (`ffprobe`), битрейт, соотношение сторон, проверку кратности разрешения (**VAE / DiT Alignment Check** на кратность 64/16/2), режим таймингов (**CFR vs VFR**) и **прогноз потребления RAM и дискового буфера**.
* **Выходы:**
  * `stream_meta` (`BLACKBOX_STREAM_META`)
  * `width`, `height` (`INT` — исходное разрешение)
  * `vae_safe_width`, `vae_safe_height` (`INT` — размеры, округлённые до кратности 16 для прямой подачи в `ImageResize` или `EmptyLatentImage` внутри Чёрного ящика)
  * `chunk_frames`, `total_frames` (`INT`)
  * `fps` (`FLOAT`)
  * `telemetry_report` (`STRING`)

---

### 3. `Blackbox Optical Flow Deflicker`
Устраняет межфреймовое мерцание, «кипение» деталей и скачки цвета после прохода через Чёрный ящик.

| Параметр | Тип | По умолч. | Описание |
| :--- | :--- | :--- | :--- |
| `images` | `IMAGE` | *Обяз.* | Кадры на выходе из вашего Чёрного ящика. |
| `raft_model` | `COMBO` | `raft_large` | Модель оптического потока: `raft_large (High Precision)` или `raft_small (Fast)`. |
| `temporal_blend` | `FLOAT` | `0.65` | Сила сглаживания по оптическому потоку между соседями (`0.0` отключает RAFT). |
| `window_radius` | `INT` | `1` | Радиус временного окна (`1` = `[t-1..t+1]`, `2` = `[t-2..t+2]`). |
| `color_stabilization` | `FLOAT` | `0.50` | Сила выравнивания яркости и цвета в пространстве LAB. |
| `occlusion_sensitivity` | `FLOAT` | `1.5` | Порог защиты от шлейфов (чем ниже, тем строже отсечение артефактов). |
| `seamless_loop` | `BOOLEAN` | `True` | Сшивает конец и начало ролика для бесшовного зацикливания. |
| `stream_meta` *(опц.)* | `META` | `None` | Передаёт контекст цвета и хвосты кадров для бесшовной склейки чанков. |

---

### 4. `Blackbox Media Saver & Muxer`
Транзакционный приёмник чанков и финальный мультиформатный кодер.

| Параметр | Тип | По умолч. | Описание |
| :--- | :--- | :--- | :--- |
| `output_format` | `COMBO` | `Auto` | `Auto`, `MP4 (H.264 + AAC)`, `WebM (VP9 + Opus)`, `WebP (24-bit)`, `GIF (256-color)`. |
| `include_audio` | `BOOLEAN` | `True` | Включает звук (из пина `audio` или из исходного видео) в MP4/WebM. |
| `speed_multiplier` | `FLOAT` | `1.00` | Множитель скорости видео с автоматической синхронизацией темпа звука (`atempo`). |
| `override_fps` | `FLOAT` | `0.0` | Принудительный FPS (`0.0` = сохранить исходные тайминги кадров). |
| `first_frame_hold_ms` | `INT` | `0` | Дополнительная пауза на первом кадре (в миллисекундах). |
| `last_frame_hold_ms` | `INT` | `0` | Дополнительная пауза на последнем кадре (в миллисекундах). |
| `playback_mode` | `COMBO` | `Normal` | `Normal (Forward)`, `Reverse (Backward)` или `Ping-Pong (Boomerang)`. |
| `loop_count` | `INT` | `0` | Число повторов для GIF/WebP (`0` = бесконечный цикл). |
| `video_crf` | `INT` | `18` | Качество видео MP4/WebM (`0..51`; `18` — визуально без потерь). Авто-выравнивание нечётных сторон. |
| `max_colors` / `dither_mode` | `INT` / `COMBO` | `256` / `None` | Палитра (`16..256` цветов) и дизеринг (`None` / `Floyd-Steinberg`) для GIF. |
| `webp_quality` / `webp_lossless` | `INT` / `BOOL` | `90` / `False` | Настройки сжатия для 24-битного анимированного WebP. |
| `output_scale` | `FLOAT` | `1.00` | Итоговое масштабирование разрешения (`0.10x .. 4.00x`, Lanczos). |
| `output_directory` | `STRING` | `""` | Папка сохранения (плюс кнопка **📂 Select Output Folder...**). |
| `filename_prefix` | `STRING` | `Blackbox_Media` | Префикс имени выходного файла (с поддержкой `overwrite_existing`). |
| `stream_meta` / `audio` | `Опц.` | `None` | Подключение `stream_meta` и внешнего `AUDIO` (для озвучки GIF/секвенций). |

## 🛠️ Установка

1. Склонируйте репозиторий в папку `ComfyUI/custom_nodes/`:
   ```bash
   cd ComfyUI/custom_nodes
   git clone [https://github.com/your-repo/ComfyUI-Blackbox-Media.git](https://github.com/your-repo/ComfyUI-Blackbox-Media.git)
   ```
2. Установите зависимости (обычно уже входят в состав ComfyUI):
   ```bash
   pip install -r ComfyUI-Blackbox-Media/requirements.txt
   ```
3. Убедитесь, что в системе установлены **`ffmpeg`** и **`ffprobe`** и они доступны в системном `PATH`.
4. Перезапустите ComfyUI и обновите страницу браузера (`Ctrl + F5`). Все ноды находятся в категории **`Blackbox Media`**.
